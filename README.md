# 🛒 All Express

A responsive shopping web app built with **React**, **Vite**, **Tailwind CSS**, **DaisyUI**, and **Shadcn**.  
Products are fetched from the [FakeStore API](https://fakestoreapi.com/), allowing users to browse items, adjust quantities, and manage their cart.

---

## 🚀 Features

- 🛍️ Browse and view products from an external API
- 🔢 Adjust item quantities using `+` and `-` buttons
- 🧮 Add items to cart and persist data using `localStorage`
- 🧾 View your cart with item details and total cost
- 🔁 Cart data is preserved even after page reload
- 📱 Fully responsive design using Tailwind CSS, DaisyUI and Shadcn
- ⚡ Built with **Vite** for fast development and hot reloading

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/all-express.git
   cd all-express
   ```
2. **Install Dependencies**
   ```bash
       npm install
   ```
3. **Start the development server**

   ```bash
       npm run dev

   ```

4. Open your browser and navigate to:

   ```bash
       http://localhost:5173

   ```

## 💾 Local Storage

The cart is saved in localStorage under the key "cart".
When users revisit the app, items are automatically restored.
